# TL_Verilog-RISCV-Instruction-Cache-w-Viz
A TL-Verilog RISC-V CPU project based on the MYTH workshop, extended with a small 2-way set-associative instruction cache. The cache tracks hits, misses, fills, set/way selection, and counters, a Makerchip VIZ panel shows cache activity visually as the CPU runs.
